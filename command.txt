Provider-specific deployment instructions removed.

This file previously contained step-by-step instructions for deploying to AWS
(EC2, ECR). That content has been removed to decouple the repository from a
single cloud provider. If you'd like, I can add a Hetzner-specific checklist
and bootstrap scripts under `deploy/`.

Quick note: to deploy on a plain Ubuntu server you generally need to:

  1. Create a non-root user and add to the docker group
     sudo useradd -m deploy && sudo usermod -aG docker deploy

  2. Install Docker & docker-compose, clone the repository, and place production
     env files under `/home/deploy/crypto-tracker/backend/.env.production` and
     `/home/deploy/crypto-tracker/frontend/.env.production`.

  3. Pull images from your registry (or build locally) and run:

     docker-compose -f docker-compose.yml -f docker-compose.prod.yml pull
     docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d

If you want a fully automated Hetzner bootstrap (cloud-init + firewall + TLS),
ask and I'll add `deploy/hetzner_bootstrap.sh` and a `DEPLOY_HETZNER.md` guide.
